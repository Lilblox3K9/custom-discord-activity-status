# Custom Discord Activity Status
Customise your discord activity status with custom icons, titles and descriptions.

## Instructions on use
[1] Open the app, enter the "Adding an activity" prompt.
[2] Submit a valid Discord Application ID (You can create an application and obtain its ID [here](https://discord.com/developers/applications)).
[3] Return to main menu and enter "Loading an activity" prompt.
[4] Select your activity.
[5] Enter a description and your activity will start broadcasting.

## Notes
This is my first time working with the discord rpc library so there may be more efficient ways of programming this, however, it still works great for its desired functions.
